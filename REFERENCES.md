## ⚠️ Licensing note for the owner (not legal advice)
React Bits adds the **Commons Clause** to MIT: it forbids *selling* the software, and the project's
LICENSE extends this to redistributing the components (including ported versions) as a
standalone product/pack. TextMotion's 12 React-Bits-inspired effects are independent Kotlin
reimplementations of visual behaviour, but distributing TextMotion publicly as a library could still
be argued to fall under that restriction. Before any public release, review the React Bits LICENSE
and/or ask the author for permission. Nothing has been published.
